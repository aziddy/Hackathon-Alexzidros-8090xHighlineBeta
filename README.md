# DevFlow

A developer productivity tool that breaks GitHub issues into atomic workflow steps, tracks progress visually, and uses AI to auto-generate step breakdowns. "The back-office secretary for developers."




### Demo Steps
1. **Login** - GitHub OAuth
2. **Select Repo** - Connect to real repo with issues
3. **Sync Issues** - Pull to Kanban board
4. **AI Magic** - Click "Generate Steps" on issue
5. **Track Progress** - Complete steps, watch bar animate
6. **Verify Status** - "Check Status" button calls GitHub API
7. **Celebrate** - 100% triggers confetti
8. **Dark Mode** - Toggle for polish
